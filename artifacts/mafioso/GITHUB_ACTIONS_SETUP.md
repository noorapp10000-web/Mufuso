# إعداد GitHub Actions لبناء APK المافيوسو

## المتطلبات

1. ارفع المشروع على GitHub
2. فعّل GitHub Actions في الإعدادات

## كيفية الاستخدام

### بناء تلقائي
- كل push على فرع `main` أو `master` يبدأ البناء تلقائياً

### بناء يدوي
1. افتح المستودع على GitHub
2. اضغط على تبويب **Actions**
3. اختر **Build Android APK — مافيوسو**
4. اضغط **Run workflow**

## تحميل الـ APK

بعد اكتمال البناء:
1. افتح نتيجة الـ workflow
2. ستجد **Artifacts** في الأسفل
3. حمّل `mafioso-apk-run<N>` — يحتوي على ملف APK
4. حمّل `build-log-run<N>` — يحتوي على السجل الكامل للبناء

## ملاحظات

- APK هو **debug** مناسب للاختبار
- يُحفظ الـ APK لمدة 30 يوماً
- يُحفظ سجل البناء لمدة 14 يوماً
- كل APK يُسمى: `mafioso-v<run>-<date>-<commit>.apk`
